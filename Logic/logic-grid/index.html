Logic Grids: turn words into marks

A logic-grid puzzle asks you to match one item from each category. A ✓ means “these belong together,” an × means “impossible,” and every row and column gets exactly one ✓.

Use the GRID method

G

Group categories

List the people, things, and order.

R

Record clues

Translate each sentence into ✓ or × marks.

I

Infer more

A ✓ forces × marks across its row and column.

D

Double-check

Read every clue against the final matches.

Worked example: click each clue

Pet parade

Maya, Noah, and Priya each bring a different pet—a cat, dog, or rabbit—and go in a different position: first, second, or third.

  1. Noah goes second.
  2. The rabbit goes immediately before the dog.
  3. Maya does not bring the cat.
  4. Priya does not go first.

Build the categories first

Before solving, make sure each category has the same number of choices. Each choice will be used exactly once.

When a clue is not direct

“Rabbit immediately before dog” creates two possible blocks: rabbit-first/dog-second or rabbit-second/dog-third. Keep both until another clue removes one.

In this puzzle, Noah is second and Priya is not first, so Maya must be first. If rabbit were second, Maya would have to bring the cat—but clue 3 says she does not. That branch is impossible.
