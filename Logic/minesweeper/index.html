Minesweeper Logic: count what remains

A clue tells how many mines touch it—including diagonals. The safest habit is to count three groups: mines already marked, unknown neighbors, and safe neighbors.

Use the COUNT method

C

Circle a clue

Work with one number at a time.

O

Outline neighbors

Include sides, corners, and diagonals.

U

Use what remains

Clue − marked mines = mines still needed.

N

Name every square

Mark a mine ● or a safe square ×.

T

Test every clue

Recount before declaring the puzzle finished.

Worked example: click a clue or step

● mine × safe ? unknown

Start with a powerful clue

Look for a clue whose unknown-neighbor count equals the number of mines it still needs.

Parent prompt: “How many mines are already marked? How many more does this clue need?”

Practice by marking the grid

Click an unknown square to cycle: ? → ● mine → × safe.

No marks yet.

Two rules that solve most puzzles

  1. All mines: if a clue needs 3 mines and has exactly 3 unknown neighbors, all three are mines.
  2. All safe: if a clue already touches its full number of marked mines, every other unknown neighbor is safe.
  3. Use new marks to unlock a nearby clue, then repeat.
  4. Never count the clue square itself.
  5. At the end, every clue must touch exactly its stated number of mines.
